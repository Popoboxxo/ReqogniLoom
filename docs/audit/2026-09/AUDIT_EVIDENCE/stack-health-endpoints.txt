## Vite dev proxy is WORKING (important for WP-3 browser tests)

`frontend/vite.config.ts` defines a proxy whose target is
`process.env.VITE_API_BASE_URL || "http://backend:8000"`, and the container
has `VITE_API_BASE_URL=http://backend:8000`.

That internal hostname `backend` is NOT resolvable from the host browser, but
that does not matter: the proxy runs INSIDE the frontend container on the
Compose network, so the browser must simply call **relative** `/api/...` paths
against `http://localhost:5173`. Proven: `GET http://localhost:5173/api/v1/artifacts/`
returned HTTP 401 (reached Django; only auth is missing) and not a 502.

**Consequence for WP-3:** drive the browser at `http://localhost:5173` and let
the app use relative API paths. Do NOT expect `http://backend:8000` to work
from the host.
